# Emergency Department Volume and Capacity

Group 2 data science project: Rogelio "Anthony" Tovar and Virgil Rogers.

* `dataset/ED.csv` – *Emergency Department Volume and Capacity, 2021–2023*, California Department of Health Care Access and Information (HCAI), via [Data.gov](https://catalog.data.gov/dataset/emergency-department-volume-and-capacity). 12,849 rows × 18 features.
* `code/exploration.ipynb` – Progress Report #1: data exploration. It reads the data from `../dataset/ED.csv`; when opened directly in Colab it loads the same file from this repository.

The project proposal is on the [Wiki](https://github.com/tovarrog24/Emergency-Department-Volume-and-Capacity/wiki/Project-Proposal).
